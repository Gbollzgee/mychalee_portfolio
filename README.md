## ⚡ Key Features

- **Cyber/Hacker Aesthetics:** Dark mode interactive UI featuring canvas-based particle/grid effects, terminal styling, and audio toggles (Lo-Fi mode).
- **Easter Eggs / Secret Modes:** Hidden activation state ("MYCHA MODE ACTIVATED") and interactive mini-canvas features.
- **Interactive Project Showcase:** Real-time links launching live projects directly from the portfolio cards.
- **Dynamic Terminal Form:** Cyberpunk-themed interactive contact/transmission module.
- **Fully Responsive:** Custom-engineered layout optimized for mobile, tablet, and 4K displays.
